WISE GOLF(운영자 황선도, 이하 "운영자")는 "골프선도부장 업로더"(이하 "업로더")를 운영합니다. 업로더는 운영자가 직접 만든 영상을 운영자 본인의 채널(유튜브 골프선도부장, 페이스북 페이지 골프선도부장, 인스타그램·스레드 @golfseondobujang)에 예약한 시간에 올리는 운영자 전용 도구입니다. 다른 사람은 이 도구에 로그인하거나 이 도구를 쓸 수 없습니다.

1. 사용하는 서비스

  • 업로더는 YouTube API 서비스를 사용합니다. 업로더를 쓰는 것은 YouTube 서비스 약관을 따르는 것이며, Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.
  • 페이스북·인스타그램·스레드에 올릴 때는 Meta의 공식 API를 사용하며, Meta의 개인정보 처리는 Meta 개인정보처리방침을 따릅니다.

2. 접근하고 처리하는 정보

  • 운영자 계정의 접근 권한(OAuth 토큰): 운영자 본인 채널에 영상을 올리는 데만 씁니다. 유튜브는 youtube.upload 권한(영상 올리기)만 요청합니다.
  • 올릴 영상과 글: 운영자가 만든 영상 파일, 제목, 설명, 태그, 공개 예정 시각.
  • 올린 결과: 각 플랫폼이 돌려주는 영상 ID·게시물 ID·주소·처리 상태. 어떤 영상이 언제 올라갔는지 관리하는 데 씁니다.

업로더는 시청자·구독자·댓글 작성자 등 다른 사람의 개인정보를 읽거나 모으지 않습니다. 운영자 계정의 다른 데이터(시청 기록, 연락처, 메일 등)에도 접근하지 않습니다.

3. 저장 위치와 보유 기간

  • 접근 토큰은 운영자만 열 수 있는 비공개 GitHub 저장소의 암호화된 보관함(GitHub Actions Secrets)에만 둡니다. 운영자가 권한을 취소하거나 도구 사용을 멈추면 바로 지웁니다.
  • 올릴 영상·글과 올린 결과 기록은 같은 비공개 저장소에 두며, 업로드 관리에 필요한 동안 보관하고 필요 없어지면 지웁니다.
  • YouTube API로 받은 정보는 위 목적 밖으로 쓰지 않고, 30일이 넘도록 새로 고치지 않은 채 쌓아 두지 않습니다.

4. 제3자 제공·판매·광고

운영자는 업로더로 처리하는 정보를 누구에게도 팔거나 제공하지 않으며, 광고·분석 도구를 쓰지 않습니다. 쿠키도 쓰지 않습니다. 다만 법령에 따른 요구가 있으면 예외로 합니다.

Privacy Policy (English)

WISE GOLF (operator: Seondo Hwang, "the Operator") runs the "Golfseondobujang Uploader" ("the Uploader"). The Uploader is a private, single-user tool that publishes videos the Operator made himself to the Operator's own channels (YouTube channel 골프선도부장, Facebook Page 골프선도부장, Instagram and Threads @golfseondobujang) at scheduled times. No one other than the Operator can sign in to or use this tool.

1. Services used

  • The Uploader uses YouTube API Services. By using the Uploader you are agreeing to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
  • Posts to Facebook, Instagram and Threads use Meta's official APIs, subject to the Meta Privacy Policy.

2. Information accessed and processed

  • Authorization tokens for the Operator's own accounts (OAuth): used only to upload videos to the Operator's own channel. On YouTube, only the youtube.upload scope is requested.
  • Content to publish: video files, titles, descriptions, tags and scheduled publish times created by the Operator.
  • Upload results: video/post IDs, URLs and processing status returned by each platform, used to keep track of what was published and when.

The Uploader does not read or collect personal information of other people (viewers, subscribers, commenters, etc.), and does not access any other data in the Operator's accounts (watch history, contacts, email, etc.).

3. Storage and retention

  • Tokens are stored only as encrypted secrets (GitHub Actions Secrets) in a private GitHub repository that only the Operator can access. They are deleted as soon as the Operator revokes access or stops using the tool.
  • Content to publish and upload logs are kept in the same private repository only as long as needed to manage uploads, then deleted.
  • Data obtained through YouTube API Services is not used for any other purpose and is not stored for more than 30 days without being refreshed.

4. Sharing, sale and advertising

The Operator does not sell or share any information processed by the Uploader with anyone, and uses no advertising or analytics tools. No cookies are used. The only exception is where disclosure is required by law.

5. How to revoke access

Access granted to the Uploader can be revoked at any time via the Google security settings page. Meta access can be removed in Facebook Settings under "Business integrations".

6. Contact

Privacy contact: Seondo Hwang (Operator) · help@wisegolf.kr

7. Changes

Any changes to this policy will be posted on this page with a new effective date.
